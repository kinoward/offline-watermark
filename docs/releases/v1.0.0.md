## English

Watermark adds repeating, multiline text to one JPG, JPEG or PDF at a time. Download **Watermark.html**, then open it in a recent browser to work offline. Files and settings stay in the current page until you refresh.

- Adjust size, density and opacity with a live preview.
- Set JPEG output quality and optionally remove EXIF while keeping the image’s visual orientation.
- Add a tiled overlay to every PDF page while retaining existing selectable text.
- Use the same editor on phones, tablets and desktops, with eight interface languages.

**SHA256SUMS** verifies the HTML and the source archive. **ImageMagick-WASM-source.tar.gz** contains the corresponding source and build instructions for the ImageMagick WASM and the libraries it statically links, including LGPL libraries. [License and dependency notices](https://github.com/kinoward/offline-watermark/blob/v1.0.0/THIRD_PARTY.md)

## 简体中文

Watermark 每次为一个 JPG、JPEG 或 PDF 平铺多行文字水印。下载 **Watermark.html** 后用较新版浏览器打开，即可断网使用。文件和设置留在当前页面，刷新会清空任务。

- 边看预览边调节水印大小、密度和透明度。
- 可设置 JPEG 导出质量，可选择清除 EXIF，同时保持照片显示方向。
- 为 PDF 每一页叠加水印，保留原有可选择的文字。
- 同一个编辑界面适配手机、平板和电脑，提供八种语言。

**SHA256SUMS** 用于核对 HTML 和源码包。**ImageMagick-WASM-source.tar.gz** 含 ImageMagick WASM 及其静态链接库的对应源码和构建说明，其中包括 LGPL 库。[许可证和依赖声明](https://github.com/kinoward/offline-watermark/blob/v1.0.0/THIRD_PARTY.md)
