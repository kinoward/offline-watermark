## English

**Watermark.html is about 21% smaller** than v1.0.0. Download it once and open it in a browser to preview, watermark, and export JPG and PDF files completely offline.

- Worker scripts and the original WebAssembly binaries are compressed separately. The browser unpacks each codec when needed.
- GitHub Pages and the offline download use the same HTML. The release workflow checks their SHA-256 hashes before updating the Latest download.

Download **Watermark.html**, then open it directly in a browser. Download **SHA256SUMS** and **ImageMagick-WASM-source.tar.gz** to the same folder and run `sha256sum -c SHA256SUMS` to verify both files. On macOS, use `shasum -a 256 -c SHA256SUMS`. The archive contains the corresponding ImageMagick WASM sources and rebuild instructions. [License and dependency notices](https://github.com/kinoward/offline-watermark/blob/v1.0.3/THIRD_PARTY.md)

## 简体中文

**Watermark.html 比 v1.0.0 缩小约 21%**。下载后直接用浏览器打开，即可完全离线预览 JPG 和 PDF、添加水印并导出。

- 分别压缩 Worker 脚本和原始 WebAssembly 二进制，浏览器在首次用到对应库时解压。
- GitHub Pages 和离线下载使用同一份 HTML。发版流程先核对两者的 SHA-256，再更新 Latest 下载。

下载 **Watermark.html** 后可直接用浏览器打开。将 **SHA256SUMS** 和 **ImageMagick-WASM-source.tar.gz** 下载到同一目录，运行 `sha256sum -c SHA256SUMS` 校验 HTML 和源码包。macOS 可用 `shasum -a 256 -c SHA256SUMS`。源码包包含对应的 ImageMagick WASM 源码和重建说明。[许可证和依赖声明](https://github.com/kinoward/offline-watermark/blob/v1.0.3/THIRD_PARTY.md)
