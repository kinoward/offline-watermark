# JPEG 重编码与元数据保真

**总结日期** 2026-11-19

[技术沉淀目录](../../../../README.zh-CN.md#技术沉淀) · [English](../../../en/technical-notes/jpeg-reencoding/README.md)

## 项目问题

Canvas 足以绘制水印图层，但浏览器的 JPEG 导出接口难以控制色度采样、渐进编码和元数据。Watermark 需要在原始分辨率合成水印，并让横竖方向和镜像在保留或清除 EXIF 后均能正确显示。

## 实现决策

1. **先读取源文件。** 解析 JPEG 标记取得存储尺寸、方向、采样和编码模式。水印先按显示方向排版，再用逆 EXIF 变换映射回原始像素坐标。用 ImageMagick WASM 合成并重新编码，显式设置质量、采样和渐进模式。[JPEG 标记解析](../../../../src/jpeg-metadata.ts) · [坐标变换](../../../../src/layout.ts) · [编码实现](../../../../src/jpeg.ts)
2. **让方向跟随导出策略。** 保留 EXIF 时，保持存储尺寸与方向标记。清除 EXIF 时，先将旋转或镜像应用到已经合成的像素，再去掉方向标记。涉及转置的方向可能交换存储宽高。[两种方向处理路径](../../../../src/jpeg.ts)
3. **重新附加受支持的元数据。** 编码后恢复 ICC 和 JFIF，保留 EXIF 的路径也恢复其中支持的内容。源图的 JFIF 和 EXIF 密度可能不同，分别保留对应数据。剥除 JFIF、JFXX 和受支持的 EXIF 缩略图，避免把未加水印的预览附回文件。清理标准 EXIF JPEG 缩略图时断开 IFD1 并清空缩略图字节，保住其他元数据的偏移。[元数据恢复与复查](../../../../src/jpeg-metadata.ts)

## 验证与边界

导出前重新解析结果，检查尺寸、采样、渐进模式、方向和恢复的元数据。单测使用渐进式 4:2:2、基线 4:2:0 和灰度样本，检查两个密度声明、清除 EXIF、缩略图和损坏输入，也解码检查合成后的像素。浏览器实测下载质量 100 和 72 的输出并比对量化表。质量 100 仍会重新编码，文件大小和压缩数据可以变化。[JPEG 单测](../../../../tests/unit/jpeg.test.mjs) · [下载件检查](../../../../tests/browser/smoke.mjs)

上述保真范围以受支持的 JPEG 标记和编码为准。解析与编码入口会拒绝不支持的类型，例如带 MPF 标记的复合 JPEG、CMYK 和超出像素限制的输入。[支持范围检查](../../../../src/jpeg-metadata.ts) · [像素上限](../../../../src/jpeg.ts)
