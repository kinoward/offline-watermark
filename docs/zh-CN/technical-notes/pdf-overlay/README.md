# PDF 逐页叠加与内容保真

**总结日期** 2026-11-19

[技术沉淀目录](../../../../README.zh-CN.md#技术沉淀) · [English](../../../en/technical-notes/pdf-overlay/README.md)

## 项目问题

把 PDF 页面渲染成位图再写回，可以保留外观，却会丢掉原有可搜索的正文，并重编码内嵌图像。Watermark 只需在现有页面上绘制水印。页面可能具有旋转、偏移的裁切区域，或者与其他页共用资源字典。

## 实现决策

1. **按可见区域确定坐标。** 取 `CropBox` 和 `MediaBox` 的交集，先裁切到该区域。按显示方向排列图块，再依据原有页面旋转和平移量映射到页面坐标，保留原来的页面框和旋转值。[页面几何与裁切](../../../../src/pdf.ts)
2. **追加绘制指令。** 用 pdf-lib 将透明图块嵌入为图像 XObject，为每页追加内容流。修改前复制可能共享的 `Contents` 数组、`Resources` 和 `XObject` 字典容器，保留原有流和资源引用，避免追加操作影响其他页。[叠加实现](../../../../src/pdf.ts)
3. **识别不适合改写的输入。** 打开时区分加密与损坏文件，并在保存前检查已有签名、时间戳或认证签名结构。空白签名字段可保留。此处的签名检测用于决定是否写入，签名真实性由专门的验签工具判断。[签名与加密处理](../../../../src/pdf.ts)

## 验证与边界

单测使用四种直角旋转、偏移裁切框和 `UserUnit` 的样本。它检查页面参数、已有压缩流的字节、追加的裁切指令和图块绘制。浏览器冒烟测试下载实际导出件，用 PDFium 从第一页提取原有正文，并用加密和已签名样本检查拒绝路径。[结构测试](../../../../tests/unit/pdf.test.mjs) · [导出与文本提取](../../../../tests/browser/smoke.mjs)

容器会重新序列化。测试的保真结论针对覆盖样本的原始页面内容流、嵌入图像流和既有正文。水印本身是透明图像图块，正文可搜索性来自原页面已有的文本。
