## 项目问题

JPEG 预览绘制在缩小的画布上，JPEG 导出使用原始像素，PDF 则使用页面单位。若各路径分别设置字号和间距，同一组水印设置会产生不同的版面比例。

## 实现决策

- **按目标短边计算图块。** 先测量多行文字中的最长行，必要时将它缩到短边的 58%。计算文字旋转 −30° 后的边界，再应用大小倍率，并限制图块最长边。这样长行的适配和用户调节大小是两个独立步骤。[图块计算](../../../../src/layout.ts)
- **分开控制间距和墨色。** `tilePositions` 按短边计算间距，间距随密度增大而缩小，每隔一行横向错开半个步长。大小控制图块尺寸，透明度在图块绘制时作用于文字 alpha。JPEG 预览和原图导出使用同一套绘制和位置计算。PDF 复用图块和位置计算，再将坐标映射到页面。[共享排版](../../../../src/layout.ts) · [PDF 放置](../../../../src/pdf.ts)
- **分开保存几何尺寸和光栅尺寸。** PDF 可以把图块渲染成更高像素密度的 PNG，再按同一逻辑宽高放置。WebKit 从 `file://` Worker 读取画布 PNG Blob 遇到 `NotReadableError` 时，用同一份画布的 RGBA 数据交给 UPNG 编码。[图块光栅化与 PNG 回退](../../../../src/layout.ts)

## 验证与边界

PDF 单测读取新增内容流，确认调大尺寸会增大绘制矩阵的宽高，调高密度会增加图块数并保持单块尺寸。浏览器测试检查改变水印文字后预览重绘。共用的是排版规则和版面比例，字体、取整和栅格分辨率会影响实际像素。[大小与间距测试](../../../../tests/unit/pdf.test.mjs) · [预览重绘检查](../../../../tests/browser/smoke.mjs)
