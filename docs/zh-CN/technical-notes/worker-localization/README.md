# 浏览器语言匹配与 Worker 消息翻译

**总结日期** 2026-11-19

[技术沉淀目录](../../../../README.zh-CN.md#技术沉淀) · [English](../../../en/technical-notes/worker-localization/README.md)

## 项目问题

页面要从有顺序的浏览器语言偏好中选出支持的译文，中文还要区分简体和繁体。文件处理错误在 Worker 中产生，显示时却要遵循界面当前语言，包括任务执行期间发生的语言切换。

## 实现决策

- **按偏好顺序匹配。** 用 `Intl.Locale` 解析语言标签，遇到无法解析或不支持的标签时尝试下一项。中文由 `maximize().script` 判断简繁体，`Hant` 对应繁体，其余对应简体。例如 `zh-Hant-CN` 匹配繁体，`zh-SG` 匹配简体。所有偏好都无法匹配时使用英语。[语言匹配](../../../../src/i18n.ts)
- **Worker 只传消息描述。** 处理 Worker 将错误转为消息键、插值参数和可选诊断详情。页面选择当前字典，并一次性替换模板中的占位符。参数中的文本逐字保留，文件名里即使含有 `{name}` 或 `$&`，也不会再次被当作模板或替换指令。[处理 Worker](../../../../src/processor.ts) · [消息格式](../../../../src/messages.ts)
- **静态界面复用同一套消息键。** HTML 用 `data-i18n` 系列属性声明文本和属性绑定。切换语言时应用字典，并同步更新文档的 `lang`。[静态绑定与语言切换](../../../../src/i18n.ts)

## 验证与边界

单测覆盖中文地区和简繁体、偏好顺序与英语回退。它核对每份字典的键集合、非空译文和占位符，并扫描 HTML 中的静态绑定。另一个用例用 `structuredClone` 模拟消息传输，验证包含占位符字面文本的文件名可按接收端语言正确显示。未知错误附带的底层诊断详情可以保留原文。[语言和消息单测](../../../../tests/unit/i18n.test.mjs)
